# Agent Bobs

**When one Bob isn't alone.** A coordination layer that lets several developers'
IBM Bob sessions on one repository see each other — and stops an agent before it
breaks another agent's work.

Built for the IBM Bob 2.0 Hackathon, 25–27 September 2026.
