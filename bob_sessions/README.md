# bob_sessions

Required submission deliverable. Every participant uploads their **own** Bob task
session summaries here. Nobody can screenshot another person's Bob account, so this
cannot be delegated.

**How** (from the official hackathon guide): Bob IDE chat → **Tasks** → select a task →
click the **task header** → screenshot the *task session consumption summary* → PNG.

**Name:** `agentbobs_<you>_task<NN>_<short-description>_summary.png`
e.g. `agentbobs_aig_task01_mcp_server_skeleton_summary.png`

Capture each one when the task finishes. They cannot be reconstructed on Sunday night.
