# bob_sessions

Required submission deliverable. Every participant uploads their **own** Bob task
session summaries here. Nobody can screenshot another person's Bob account, so this
cannot be delegated.

**How** (from the official hackathon guide): in the IBM BOB panel click the **Tasks**
icon (the ✓≡ checklist, between the gear and **+**) → select the task → click the
task's **title text** at the top-left of the chat panel. Not the token count and not
the coin badge on the right — those only open tooltips. A panel titled **Task** opens,
showing the Task Id, Workspace and Bobcoins. Screenshot that panel as a PNG.

**Name:** `imagic_<lablab-username>_task<NN>_<short-description>_summary.png`
- `imagic` — our team name, iMAGIC, as the guide asks. Always lowercase, so all
  four people's files sort together.
- `<lablab-username>` — ties the screenshot to a registered participant.
- `<NN>` — your own task count, starting at 01.

Capture each one when the task finishes. They cannot be reconstructed on Sunday night.
